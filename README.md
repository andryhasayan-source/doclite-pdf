# DocLite PDF

**Рабочий центр документов прямо в браузере: объединение, сжатие, Word
и Excel, подписи и печати, пароль на PDF, работа со страницами
и распознавание текста (OCR). Документы обрабатываются на вашем компьютере
и никуда не загружаются.**

## Что это

Расширение для Google Chrome, которое делает с PDF всё нужное в повседневной
работе — и делает это, не отправляя ваши файлы на чужой сервер.

Обычный онлайн-конвертер принимает документ к себе. Где он там лежит, сколько
хранится и кто имеет к нему доступ — вопрос доверия. Для квитанции за свет это
неважно. Для договора с клиентом, скана паспорта или бухгалтерского отчёта —
важно очень.

DocLite работает внутри браузера. Файл не передаётся никуда: расширению не нужен
интернет, чтобы объединить или конвертировать PDF. Можно отключить сеть и
убедиться самому.

## Инструменты

| | Что делает |
|---|---|
| **Объединить** | Несколько файлов в один; порядок — перетаскиванием, стрелками, с номерами |
| **Разделить** | По страницам или диапазонам, результат одним архивом |
| **Сжать** | Уменьшает вес для почты; большие файлы сжимаются в фоне |
| **JPG → PDF** | Фотографии и сканы в один файл, в нужном порядке |
| **PDF ↔ Word** | Абзацы, таблицы с рамками, картинки и оформление остаются на местах |
| **PDF ↔ Excel** | Таблицы с рамками и объединёнными ячейками, суммы и даты — значениями |
| **Подпись и печати** | Подпись, печать, штамп «Копия верна» — на одну страницу или на все |
| **Водяной знак** | Текст или картинка; можно сразу на несколько файлов |
| **Нумерация** | Номера страниц в любом углу; можно сразу на несколько файлов |
| **HTML → PDF** | Веб-страница или свой HTML сохраняется как документ |
| **Страницы** | Миниатюры страниц: переставить, повернуть, удалить |
| **Пароль** | Поставить или снять пароль на PDF, шифрование AES-256 |
| **Распознать текст (OCR)** | Скан или фото — в PDF с текстовым слоем или в Word; есть точный режим |

Распознавание, конвертация больших PDF в Word и сжатие больших файлов идут
в фоне: поставили задачу, закрыли окно, занимаетесь своими делами — по
готовности придёт уведомление с предложением сохранить результат.

## Приватность

- Содержимое документов не покидает ваш компьютер и не передаётся никому.
- В сеть уходят только два вида запросов: проверка ключа при активации
  платной версии и — один раз, только если вы сами включите распознавание
  текста — скачивание языковых моделей OCR (около 4 МБ на язык, для точного
  режима около 15 МБ; дальше распознавание работает офлайн).
- Пароль на PDF ставится и снимается на вашем компьютере: пароль никуда
  не отправляется и нигде не сохраняется.
- Ни аналитики, ни счётчиков, ни рекламных сетей в расширении нет.
- Доступа к содержимому посещаемых сайтов расширение не запрашивает.

Подробнее — в [политике конфиденциальности](https://www.shashevpro.ru/doclite/privacy.html).

## О чём стоит знать заранее

Здесь честно про границы, чтобы не было обманутых ожиданий:

- **Сжатие переводит страницы в изображение** — текст в результате перестаёт
  выделяться. Если документ должен остаться редактируемым текстом, используйте
  объединение или разделение без сжатия.
- **PDF → Word и PDF → Excel работают с текстовыми PDF, а не со сканами.**
  Для сканов и фото — отдельный инструмент, распознавание текста (OCR).
- **Вёрстка при конвертации сохраняется близко к исходной, но не пиксель
  в пиксель** — сложные документы стоит проверить глазами.
- **OCR распознаёт русский и английский языки** и убирает явный мусор
  (узоры, печати, водяные знаки), но не гарантирует идеальный результат
  на сильно повреждённых или очень мелких сканах. Для мелкого шрифта и плохих
  сканов есть точный режим — он медленнее примерно в 2,5 раза. Документы
  с защитной сеткой (бланки, паспорта) распознаются лишь частично.
- **Если в PDF уже есть текст, распознавание не запускается** — текст берётся
  из документа, это точнее любого распознавания. В документе со смешанными
  страницами распознаются только страницы без текста.
- **Excel → PDF не переносит картинки внутри листа** (логотипы, печати)
  и колонтитулы.
- **Снять пароль можно, только зная его.** Файл, который открывается без
  пароля, но с ограничениями на печать или изменение, освобождается от них
  без пароля. Другие инструменты защищённый файл не обрабатывают и
  подсказывают сначала снять пароль.
- **Размер файлов** — до 300 МБ на файл и до 600 МБ суммарно при объединении:
  всё обрабатывается в памяти браузера.
